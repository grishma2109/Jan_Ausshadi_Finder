# Jan-Aushadhi Finder

## AI-Powered Healthcare Savings & Generic Medicine Finder

Jan-Aushadhi Finder is a healthcare-focused web application designed to help users discover affordable generic medicines and locate nearby Jan-Aushadhi Kendras. The platform promotes affordable healthcare accessibility by helping citizens compare branded medicines with low-cost generic alternatives.

# Problem Statement

Generic medicines available at Jan-Aushadhi stores are significantly cheaper than branded medicines. However, many people are unaware of:

* Nearby Jan-Aushadhi Kendras
* Generic alternatives for branded medicines
* Potential cost savings
* Availability of medicines

This project solves these challenges through an intelligent medicine search and healthcare savings platform.

---

# Project Vision

Jan-Aushadhi Finder acts as a Healthcare Savings Tool by:

* Helping users locate nearby Jan-Aushadhi stores
* Translating branded medicines into generic equivalents
* Showing medicine price comparisons
* Calculating healthcare savings
* Improving awareness about affordable medicines

The project supports the mission of accessible and affordable healthcare for all citizens.

# Features

## Medicine Search

* Search medicines using branded medicine names
* Get generic/salt equivalents instantly
* Intelligent fuzzy search support for spelling mistakes
* Fast and responsive search functionality

### Example

| Medicine Type    | Price |
| ---------------- | ----- |
| Branded Medicine | ₹100  |
| Generic Medicine | ₹20   |
| Total Savings    | ₹80   |

---

## Store Locator

* Find nearby Jan-Aushadhi Kendras
* Google Maps integration
* Nearby store search within 10 km
* Simulated “Open Now” availability status

---

## Stock Request System

* Simulated medicine stock availability request
* Helps users check medicine availability at nearby stores

---

## Monthly Medicine Reminder

* Medicine refill reminder system
* Useful for long-term prescriptions and chronic patients

---

## Savings Calculator

* Calculates estimated savings when switching to generic medicines
* Encourages affordable healthcare adoption

# Installation & Setup

## Prerequisites

* Node.js installed
* Gemini API Key

---

## Step 1: Clone Repository

```bash
git clone https://github.com/grishma2109/Jan_Ausshadi_Finder.git
```

---

## Step 2: Navigate to Project Folder

```bash
cd Jan_Ausshadi_Finder
```

---

## Step 3: Install Dependencies

```bash
npm install
```

---

## Step 4: Configure Environment Variables

Create a `.env.local` file and add:

```env
GEMINI_API_KEY=your_api_key_here
```

---

## Step 5: Run the Application

```bash
npm run dev
```
